## 🚀 Featured Projects

### 🛍️ FLASHSHOP – AI-Powered E-Commerce Platform

> Production-grade MERN e-commerce store with a Gemini-powered shopping copilot, RAG with verified citations, and an automated LLM evaluation framework.

[![GitHub](https://img.shields.io/badge/GitHub-View_Repo-181717?style=flat-square&logo=github)](https://github.com/Gulshankartikk/e-commerce-website)
[![Live Demo](https://img.shields.io/badge/Live-Storefront-087F65?style=flat-square&logo=vercel&logoColor=white)](https://e-commerce-website-seven-steel.vercel.app)
![MERN](https://img.shields.io/badge/Stack-MERN-63b3ed?style=flat-square)
![AI](https://img.shields.io/badge/AI-Gemini_RAG-8E75B2?style=flat-square)

- 🧠 **Production RAG with verified citations** — 768-d Gemini embeddings, MongoDB Atlas Vector Search with cosine-similarity fallback, and a server-side validator that strips hallucinated citations
- 🛡️ **Prompt-injection defense** — retrieved chunks and user input isolated in XML boundaries; strict abstention on out-of-scope queries
- 📊 **Automated LLM evaluation framework** — versioned 17-case benchmark measuring Recall@k, MRR, citation precision, faithfulness, abstention accuracy, latency & cost, with a CI quality gate
- 👥 **Multi-role system** — Customer, Admin, Manager & Seller with RBAC, sales analytics, inventory CRUD, coupons and order fulfilment
- 🛒 **Complete commerce flow** — persistent cart, wishlist, address book, checkout, PDF invoices
- ✅ **Tested** — 34-assertion API integration suite + backend unit tests
- 🚀 **Deployed** — Vercel (frontend) + Render (API) + MongoDB Atlas

**Tech:** `React 18` `Vite` `Tailwind CSS` `Redux Toolkit` `Framer Motion` `Node.js` `Express` `MongoDB Atlas` `Google Gemini` `JWT` `Vercel` `Render`

### 💬 Flash Chat – Real-Time Communication & Social Platform

> Production-grade, WhatsApp-style messaging platform with voice/video calls, an Instagram-style social engine, a private data vault and Gemini AI built in.

[![GitHub](https://img.shields.io/badge/GitHub-View_Repo-181717?style=flat-square&logo=github)](https://github.com/Gulshankartikk/Flash-chat)
![MERN](https://img.shields.io/badge/Stack-MERN-63b3ed?style=flat-square)
![Real-time](https://img.shields.io/badge/Real--time-Socket.IO_%2B_WebRTC-fc8181?style=flat-square)

- ⚡ **Socket.IO** messaging for 1-to-1 & group chats with typing indicators, read receipts, reactions, edit/delete and cursor-based infinite scroll
- 📞 **WebRTC voice & video calling** (mesh, group-capable) with a Coturn STUN/TURN server in Docker
- 🔐 **Dual auth** — Google OAuth 2.0 + JWT in httpOnly cookies, plus Gmail/Nodemailer notifications with retry queue
- 🤖 **Flash AI (Gemini)** — smart replies, translation, chat summaries, `@ai` bot, and RAG search over a personal vault
- 📸 **Social engine** — posts, reels, 24h stories, explore, hashtags & notifications on a unified contact graph
- 🔒 **Pocket vault** — client-side AES-GCM-256 encryption, PIN/auto-lock and SSRF-hardened link previews
- 🛡️ **Security hardening** — Helmet, CORS whitelisting, rate limiting, NoSQL-injection sanitization, RBAC, Pino log redaction
- 🐳 **DevOps-ready** — Docker Compose (prod/staging), Nginx, load tests and monitoring docs

**Tech:** `React 18` `Vite` `Tailwind CSS` `Zustand` `Node.js` `Express` `MongoDB` `Socket.IO` `WebRTC` `Redis (optional)` `Docker` `Nginx` `Gemini`
